## Build failure analysis (attempt 1)

`Could not create task ':react-native-async-storage_async-storage:kspDebugKotlin'` → `'org.gradle.api.provider.Property org.jetbrains.kotlin.gradle.tasks.KotlinCompile$ClasspathSnapshotProperties.getUseClasspathSnapshot()'`.

Cause chain: the template pins Kotlin Gradle plugin 2.4.21 (`android/build.gradle:9`). async-storage 3.1.1's `android/config.gradle` picks its KSP plugin by Kotlin version, has no entry for 2.4.21, and falls back to KSP `2.1.0-1.0.28`; that plugin calls `KotlinCompile$ClasspathSnapshotProperties.getUseClasspathSnapshot()`, which was removed from the Kotlin 2.4.21 Gradle API (verified with `javap` against both jars in the Gradle cache). Fix: async-storage's documented override `AsyncStorage_kspVersion` (checked in `getConfigValueOrDefault`: `AsyncStorage_kspVersion` property wins) set to `2.3.12` — KSP 2.3.x is version-decoupled from Kotlin patch releases (KSP2). Documented in README `## Checks`.
